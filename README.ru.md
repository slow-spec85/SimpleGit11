<h1 align="center">SimpleGit11</h1>

<p align="center">
  Графический Git-клиент для Windows 11 на WinUI 3
</p>

SimpleGit11 — графический клиент над установленным `git.exe`, выполненный в
стиле Windows 11. Приложение предоставляет интерфейс для повседневной работы с
локальными и удалёнными репозиториями, но не заменяет Git и использует его
команды для выполнения операций.

> [!IMPORTANT]
> Проект находится на стадии предварительного выпуска. До стабильной версии
> 1.0 интерфейс, поведение и формат настроек могут изменяться.

## Возможности

- **Репозитории:** открытие существующих, создание и клонирование репозиториев;
  поиск репозиториев в выбранной папке; список недавних репозиториев; просмотр
  состояния, текущей ветки, upstream и данных пользователя Git.
- **Изменения и коммиты:** просмотр staged, unstaged, untracked и конфликтующих
  файлов; diff с подсветкой и режимом полного файла; staging и unstaging
  отдельных файлов или всех изменений; откат строк и файлов; встроенное
  редактирование файлов; создание коммитов и amend последнего коммита.
- **Незавершённые операции и stash:** продолжение, пропуск или отмена merge,
  rebase, cherry-pick и revert; создание, применение, pop и удаление stash.
- **История:** постраничный просмотр коммитов и их содержимого, сравнение
  ревизий, revert коммита, а также soft, mixed и hard reset.
- **Ветки и теги:** локальные и удалённые ветки, lightweight и annotated tags;
  создание, переименование, удаление и checkout; настройка upstream и push
  remote; merge, squash merge и rebase; сравнение веток и просмотр reflog.
- **Удалённые репозитории и синхронизация:** добавление, переименование и
  удаление remotes, изменение URL, fetch, pull и push; отправка отдельных веток
  и тегов, всех ожидающих изменений или atomic push; отображение входящих и
  исходящих изменений.
- **Worktree:** создание, открытие, перемещение, блокировка, разблокировка и
  удаление worktree, а также prune и repair.
- **Разрешение конфликтов:** встроенный редактор с выбором current, incoming
  или обоих вариантов, ручным редактированием строк, undo/redo и пометкой файла
  как разрешённого.
- **Дополнительные инструменты:** архивирование выбранной ревизии в ZIP,
  TAR.GZ или TAR; автоматическое обновление состояния при внешних изменениях
  репозитория; настройка Git user, email, default branch, push remote и
  credential helper.
- **Интерфейс Windows 11:** системная, светлая и тёмная темы; английский и
  русский языки; настраиваемые шрифт, размер и межстрочный интервал редактора;
  общие индикаторы длительных операций и сообщения об ошибках, сохраняющиеся
  при переходе между страницами.

## Системные требования

- Windows 11 x64;
- Git for Windows: `git.exe` должен быть доступен через `PATH`.

Готовая сборка распространяется как **unpackaged, self-contained, win-x64**
приложение. .NET и Windows App SDK входят в дистрибутив, поэтому установка
отдельного .NET Runtime, сертификата или права администратора не требуются.

## Установка

1. Скачайте `SimpleGit11-<version>-win-x64.zip` и соответствующий файл
   `.sha256` со страницы Releases репозитория.
2. При необходимости проверьте контрольную сумму.
3. Полностью распакуйте ZIP в постоянную папку.
4. Запустите `SimpleGit11.exe`.

Не запускайте приложение непосредственно из ZIP: для работы требуется всё
содержимое архива. Автоматическое обновление пока не реализовано. Подробные
инструкции по установке, обновлению и проверке SHA-256 приведены в
[PUBLISHING.ru.md](PUBLISHING.ru.md).

## Сборка из исходного кода

Потребуются .NET SDK 10, совместимый Windows SDK и Git for Windows.

```powershell
dotnet restore .\SimpleGit11.slnx
dotnet build .\SimpleGit11.slnx -c Debug -p:Platform=x64
```

Проект собирается только для `x64`. Подробности о локальной сборке и подготовке
релизных ZIP-архивов находятся в [PUBLISHING.ru.md](PUBLISHING.ru.md).
