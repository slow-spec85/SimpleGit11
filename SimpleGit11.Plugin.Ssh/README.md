# SSH-плагин SimpleGit11

Необязательный модуль для работы с репозиториями на другой машине через SSH/SFTP.
Содержит библиотечный транспорт SSH.NET, профили, существующий диалог настройки
и команду «Подключение по SSH» с индикатором подключения. Основное приложение
не зависит от сборки плагина. Без установки модуля SSH-команда отсутствует.

## Сборка x64

Из корня репозитория:

```powershell
dotnet build SimpleGit11.slnx -c Debug -p:Platform=x64
dotnet test SimpleGit11.slnx -c Debug -p:Platform=x64 --no-build --no-restore
```

Плагин можно собрать отдельно:

```powershell
dotnet build SimpleGit11.Plugin.Ssh/SimpleGit11.Plugin.Ssh.csproj -c Debug -p:Platform=x64
```

Версия плагина формируется MinVer из того же Git-тега и коммита, что и версия
приложения. При сборке создаётся `plugin.json` с этой версией; вручную менять
версию в коде или manifest не требуется. Сборка MSI дополнительно передаёт
плагину точную версию публикуемого приложения и проверяет их совпадение.

Готовый набор файлов:

```text
SimpleGit11.Plugin.Ssh/bin/x64/Debug/net8.0-windows10.0.19041.0/win-x64/Plugin/
  plugin.json
  SimpleGit11.Plugin.Ssh.dll
  SimpleGit11.Plugin.Ssh.deps.json
  Renci.SshNet.dll
  BouncyCastle.Cryptography.dll
  Microsoft.Extensions.Logging.Abstractions.dll
```

WinUI, CommunityToolkit.Mvvm, DI-контракты и SimpleGit11.Extensibility
предоставляются приложением. Их копии в комплект плагина не входят.

## Установка через MSI

В установщике включите компонент **Поддержка SSH**. Для добавления или удаления
плагина повторно откройте исходный MSI и измените состав компонентов.
Предварительно закройте приложение. Удаление только плагина сохраняет SSH-профили.
Сборка MSI описана в [инструкции публикации](../PUBLISHING.ru.md#подготовка-msi).

## Ручная установка для ZIP и отладочной сборки

1. Закройте SimpleGit11.
2. Скопируйте содержимое каталога `Plugin` в `Plugins/Ssh` рядом с `SimpleGit11.exe`.
3. Запустите приложение: появится команда «Подключение по SSH».

Для отладочной сборки каталог установки находится в
`SimpleGit11/bin/x64/Debug/net8.0-windows10.0.19041.0/win-x64/Plugins/Ssh`.
Не копируйте полный выходной каталог сборки плагина поверх приложения.
Обновляйте комплект целиком, не смешивая файлы разных версий.

Чтобы отключить плагин, при закрытом приложении переместите `Plugins/Ssh`
за пределы каталога `Plugins`. После запуска команда и SSH-провайдер исчезнут.
Настройки профилей не удаляются и снова доступны после установки модуля.
При обновлении с прежней встроенной реализацией ID профилей и доверенные ключи
сохраняются. Пароли и парольные фразы по-прежнему не записываются на диск.

Пока соединение активно, повторное нажатие команды отключает его — это указано
в подсказке. Выбор локального/удалённого режима определяется подключением,
а не открытым репозиторием. Обычные SSH-remotes самого Git и SSH-подписи
не требуют этого плагина.

## Проверки и ограничения

Тесты плагина находятся в `SimpleGit11.Plugin.Ssh.Tests`; тесты реальной
динамической загрузки и отсутствия модуля — в `SimpleGit11.Tests`.
Сетевой интеграционный тест запускается только при заданных
`SIMPLEGIT11_SSH_TEST_HOST`, `SIMPLEGIT11_SSH_TEST_USERNAME`,
`SIMPLEGIT11_SSH_TEST_HOST_KEY`, `SIMPLEGIT11_SSH_TEST_DIRECTORY`.
При необходимости задаются порт и ключ/пароль через переменные, описанные
в `SshExecutionIntegrationTests`. Учётные данные не следует хранить в репозитории.

Установка на лету не поддерживается. Загружается доверенный код внутри процесса;
проверка подписи плагина остаётся отдельным этапом.
